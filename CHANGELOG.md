# Changelog

What changes for you in each release of the Kumiko app. `npm run release <version>` dates the newest heading.

## 0.1.0

First release. Kumiko is mission control for your coding agents: each project gets a sandbox the agent owns, so it
works without permission prompts while your machine stays out of reach. Run many sessions across your projects, and see
at a glance which ones need you.

Today the sandboxes are [Lima](https://lima-vm.io) VMs and the agent is Claude Code. Kumiko runs on macOS, on Apple
silicon and Intel.
