Work turns up other work. The agent finds a bug on the way, or a follow-up that would crowd the task at hand. It
doesn't have to do everything in one conversation.

A session's agent knows the other sessions of its sandbox, and no other sandbox's:

- It lists them, open and saved, by name and description, to find work already under way before it starts more.
- It proposes a new session, with an opening prompt it writes and the artifacts it wants to give it. You see the
  prompt in the chat, with **Start session** and **Decline**. Nothing starts until you accept.
- It shares artifacts with another open session. That session gets copies, and its agent hears of them with your next
  message there.

A new session starts fresh, in `/workspace`, with only its prompt and the copies. The agent isn't told whether you
started it.
