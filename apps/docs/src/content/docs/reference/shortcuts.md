<kbd>Cmd</kbd> on macOS is <kbd>Ctrl</kbd> elsewhere.

## Tabs

| Keys | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | Open a New session tab |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | Reopen the last session you closed |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Close the tab. The session stays saved. |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | Close the tab and delete the saved session, after asking |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> | Go to the next tab |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>[</kbd> | Go to the previous tab |
| <kbd>Cmd</kbd>+<kbd>1</kbd> to <kbd>9</kbd> | Go to that tab, counting from the first tab after **Sandboxes** |

The next and previous tab skip the tabs of sandboxes whose tabs you hid.

## The message box

| Keys | Does |
| --- | --- |
| <kbd>Enter</kbd> | Send |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Start a new line |
| <kbd>Esc</kbd> | Stop the turn the agent is working on |
| <kbd>Tab</kbd> | Take the agent's suggested message, or the highlighted slash command |
| <kbd>↑</kbd> and <kbd>↓</kbd> | Move through slash commands, or, at the start or end of the box, through the messages you sent before |
| <kbd>↑</kbd> at the start of the box | Take back a queued message to edit it |
| <kbd>!</kbd> in an empty box | Switch to [shell mode](/guide/prompts/#run-a-shell-command) |
| <kbd>Backspace</kbd> at the start of the box | Leave shell mode |
| <kbd>↑</kbd> and <kbd>↓</kbd> in shell mode | Move through the commands you ran before |

## The chat

| Keys | Does |
| --- | --- |
| <kbd>Q</kbd> | Quote the selected text into the message box |
| A number key | Pick that option of the question that has focus |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Show or hide the Tasks pane |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Move the commands the agent is waiting on to the background |
| <kbd>Cmd</kbd>+<kbd>Enter</kbd> | Send what you wrote when declining a card |

## Artifacts

| Keys | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Open the list of the session's artifacts |
| <kbd>↑</kbd> and <kbd>↓</kbd> in the list | Move |
| <kbd>Enter</kbd> in the list | Show or hide the artifact |
| <kbd>Esc</kbd> in the list | Close the list |

## The review pane

| Keys | Does |
| --- | --- |
| <kbd>j</kbd> | Go to the next file |
| <kbd>k</kbd> | Go to the previous file |
| <kbd>v</kbd> | Mark the file viewed |
| <kbd>Cmd</kbd>+<kbd>Enter</kbd> in a note | Save the note |
| <kbd>Esc</kbd> in a note | Drop the note |
