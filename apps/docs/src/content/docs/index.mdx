<CardGrid>
  <Card title="A sandbox the agent owns" icon="seti:lock">
    The agent works in a VM of its own, without permission prompts. The rest of your Mac stays out of reach.
  </Card>
  <Card title="Pushes you approve" icon="seti:git">
    The agent pushes to a mirror on your Mac. Its work reaches GitHub only when you approve it on a card.
  </Card>
  <Card title="Many sessions, one overview" icon="comment">
    Run sessions in parallel across sandboxes, each in its own worktree, and see which ones need you.
  </Card>
  <Card title="Agents that outlive the app" icon="laptop">
    Quit or restart Kumiko and the agents keep working. The VM can be rebuilt without losing the repos.
  </Card>
</CardGrid>
