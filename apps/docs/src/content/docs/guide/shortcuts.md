<kbd>Cmd</kbd> on macOS, <kbd>Ctrl</kbd> elsewhere.

## Tabs

| Keys | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | New session tab |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | Reopen the last closed session |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Close the tab (the session stays saved) |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | Close the tab and delete the saved session, after asking |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Next / previous tab |
| <kbd>Cmd</kbd>+<kbd>1</kbd>…<kbd>9</kbd> | The nth tab after Projects |

## The message box

| Keys | Does |
| --- | --- |
| <kbd>Enter</kbd> | Send |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | New line |
| <kbd>Esc</kbd> | Stop the turn the agent is working on |
| <kbd>Tab</kbd> | Take the agent's suggested message, or the highlighted slash command |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move through slash commands |

## The chat

| Keys | Does |
| --- | --- |
| <kbd>Q</kbd> | Quote the selected text into the message |

## Artifacts

| Keys | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Open the list of the session's artifacts: <kbd>↑</kbd> / <kbd>↓</kbd> to move, <kbd>Enter</kbd> to show or hide one, <kbd>Esc</kbd> to close it |
